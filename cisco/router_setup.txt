1. HWIC Slot requirement: Cisco 2900 series routers do not have onboard serial ports by default. You must power down the router, insert the HWIC-2T (high-speed serial WAN interface card) into slot 0, and power the router back on.

2. Cables:
Copper Straight-Through: Connects PC FastEthernet ports to Router GigabitEthernet ports (unlike-layer devices).
Serial DCE Cable: Connects R0 (Serial 0/3/0) to R1 (Serial 0/3/0). The DCE end provides clock synchronization to the DTE end.  


The Four IOS Modes
User EXEC Mode (Router>): Default upon connecting. Basic view-only diagnostic commands (e.g., ping, traceroute).  
Privileged EXEC Mode (Router#): Accessed via the enable command. Full read access to system status, configuration files, and deep diagnostics (show commands, debug, reload).   
Global Configuration Mode (Router(config)#): Accessed via configure terminal (or shortcut conf t). Changes affect the entire router globally (e.g., hostname, routing protocols, static host tables).   Interface Configuration Mode (Router(config-if)#): Accessed via interface <type> <slot/port>. Changes affect only the specific physical or virtual port (e.g., ip address, no shutdown, clock rate).
